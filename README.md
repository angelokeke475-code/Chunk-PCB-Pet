# Chunk-PCB-Pet
A PCB Powered Seal Pet for Hackclub's Half-Life
## Description
A PCB pet utilizing the guide from Half-Life week 1: Starbie to make a seal pet. It features two key buttons, a screen, and a sensor that allows for interaction.

## Getting Started
### Dependencies
- A device that can upload Arduino code into an ESP32.
- Everything on the BOM list.
- Access to soldering materials or a company that can manufacture the board.
## Installing
Open .ino file in Arudino IDE and upload code into the esp-32.
### Executing Program
- Ensure all parts are installed
- Ensure Program is uploaded to Esp-32 
- Interact with the controls
